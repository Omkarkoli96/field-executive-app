Batch Address Verification

Upload a Customer Data file and a Visited Data file (e.g. addresses collected offline). Each row is matched by Loan_ID, both addresses are geocoded, and compared against the verification radius (currently {{ current_radius_km }} km). The result downloads as an Excel file as soon as you submit. This is separate from the live GPS-capture flow field executives use — it never touches that log.

Required: Loan_ID, Customer_Address. Optional: Customer_Name, Customer_Latitude + Customer_Longitude (used instead of geocoding when present).

Required: Loan_ID, Visited_Address. Optional: Executive_Name, Visit_Date, Visited_Latitude + Visited_Longitude (used instead of geocoding when present).

Processing — geocoding new addresses can take a few seconds each the first time. Already-seen addresses use the cache and are instant. Your download will start automatically.
Rows are marked VERIFIED (≤{{ current_radius_km }} km), NOT_VERIFIED (>{{ current_radius_km }} km), COULD_NOT_GEOCODE (a location couldn't be resolved), or LOAN_ID_NOT_FOUND (no matching customer record). The result also shows a Location_Source column for each side — GPS means exact coordinates were used; "Address (approx)" means the text was geocoded, which is less reliable for landmark names.
